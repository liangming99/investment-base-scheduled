# 输出风险档案

| 风险 | 失真方式 | 当前护栏 | 仍缺证据 |
|---|---|---|---|
| 配置漂移 | 旧 ID、时间或字段被当成当前事实 | 每次运行前 `workflow-list/get`；baseline 只作线索 | 长期漂移监测 |
| 重复写入 | 同周槽位、候选或通知被重复创建 | 项目+周槽位、记录身份、状态标记、待通知锁 | 外部 runner 的幂等回归 |
| AI 臆造 | 周报摘要、状态或领导变化超出原文 | 证据门、严格枚举、NO_CHANGE/NONE 分支 | provider 版本与输出评测 |
| 误发消息 | 收件人或变化判断错误 | 先解析唯一收件人；NOTIFY 才发送；读回消息 ID | 外部 Agent 消息/出网权限 |
| 日期误判 | 节假日、时区或截止时间算错 | Asia/Shanghai；holiday-unverified 时停止 | 法定节假日历与自然运行 |
| 验收越界 | 配置读回被报告成生产或业务通过 | 分离本地检查、外部读回、业务验收 | 真实多账号走查 |
